class libredte_lib_sdk.billing.integration.request.SiiRequestOptions(retries: int | None = None, timeout: int | None = None, max_duration: int | None = None)

Bases: object

Reintentos y tiempos de una llamada al SII.

Cada valor es opcional: el que no se indica lo resuelve la API con el suyo. La API ajusta cada valor a su rango.

  • retries: cantidad máxima de intentos de la llamada, de 1 a 10.

  • timeout: segundos máximos de cada intento, de 10 a 60.

  • max_duration: segundos máximos de la llamada, sumando sus intentos y las pausas entre ellos, de 10 a 300. La autenticación con el SII es una llamada aparte, con su propio tiempo.
